# Architecture decision records

Significant decisions are recorded here as short ADRs, one file per decision:

```text
NNNN-short-title.md   e.g. 0001-single-cluster-scope.md
```

Each ADR states:

- **Status:** proposed, accepted, superseded or rejected
- **Context**
- **Decision**
- **Consequences:** including cost and operational impact
- **Evidence:** links to documentation or experiment results

A superseded ADR is kept and linked to the ADR that replaces it.
